# gen_assets — procedural asset pipeline

Every model and texture in `assets/` is generated by the scripts here.
Only Python 3 + numpy + Pillow are needed. Nothing is downloaded.

```
python3 tools/gen_assets/build_all.py        # textures -> environment -> food
cd <project> && ~/.local/bin/godot --headless --path . --import   # (re)import in Godot
```

Preview contact sheets (software GL, writes `qa/*_preview.png`):

```
xvfb-run -a -s "-screen 0 1600x900x24" ~/.local/bin/godot --path . \
    --rendering-driver opengl3 --resolution 1600x900 \
    -s tools/gen_assets/preview.gd -- --sheet=all
# --sheet=assets|props|interior|food|all
# ad-hoc close-up: --sheet=closeup --only=food_taco,storefront --spacing=0.3 --cols=3 --pitch=20
```

## Files

| script | purpose |
|---|---|
| `glb.py` | GLB 2.0 writer + geometry helpers (`box`, `cylinder`, `cone`, `sphere`, `ellipsoid`, `torus`, `disc`, `extrude` (polygon, ear-clipped), `lathe`/revolve, `tube` (sweep along a path), `wavy_polygon`, `rounded_rect`, `Geo.translate/rotate_*/scale/flip/jitter`, `merge`). Everything is a triangle soup with per-face normals = flat shading. One mesh per file, one primitive per `Material`. Colours are sRGB in, converted to linear for glTF. Textures are referenced by relative URI `../textures/<name>.png`. |
| `gen_textures.py` | 512x512 tileable, painterly PNGs -> `assets/textures/` |
| `gen_environment.py` | buildings, storefront, ground tiles, street props, furniture -> `assets/models/` |
| `gen_food.py` | one clickable food piece per file -> `assets/models/food_*.glb` |
| `build_all.py` | runs the three generators |
| `preview.gd` | Godot SceneTree script that renders the contact sheets |

Conventions: 1 unit = 1 m, Y up, **origin at ground/bottom centre**, fronts face **+Z**.
Materials are PBR, metallic 0, roughness ~0.9 (food sauces/glass lower). Back-face
culling is on everywhere except awning fabric and palm fronds (double sided).

## Adding an asset

1. Write a function returning a `Geo` in `gen_environment.py` / `gen_food.py`
   (compose the helpers, keep the bottom at y=0 and the footprint centred).
2. Add it to the `ASSETS` / `FOODS` list, run `build_all.py`, re-import, re-render
   the sheet and look at it. Winding must be CCW-outward (helpers guarantee it;
   `Geo.flip()` if you build raw triangles inside-out).
