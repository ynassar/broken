# Man v Man v Food — Architecture

Engine: **Godot 4.3**, GDScript, GL Compatibility renderer (runs on weak GPUs, web export, and software GL for CI screenshots).

## Layout
```
project.godot
src/
  main.tscn / main.gd          # root scene: world + player + UI layers, game flow
  autoload/events.gd           # global signal bus (Events)
  autoload/data.gd             # static data loader (Data): challenges, items, skills, regions
  autoload/game_state.gd       # persistent player state (GameState): money, subs, inventory, skills, hostiles, save/load
  eating/eating_sim.gd         # pure eating simulation (no nodes) — unit tested
  eating/eating_minigame.*     # 3D table scene + HUD that drives EatingSim
  economy.gd                   # static formulas: video revenue, subs, loot, bills — unit tested
  player/                      # third-person controller
  npc/                         # hostile owner AI
  world/                       # city block, restaurant, props
  ui/                          # HUD, dialogs, shop, video result
assets/
  models/*.glb                 # generated by tools/gen_assets/*.py (no external assets)
  textures/*.png               # generated
  characters/*.tscn            # primitive-built rigs with procedural animation
data/
  challenges/*.json  items.json  skills.json  regions.json
tests/                         # headless GDScript tests: `godot --headless -s tests/run.gd`
tools/                         # asset generators, screenshot/QA harness
qa/                            # screenshots produced by QA runs (gitignored)
```

## Conventions
- Units: 1 unit = 1 metre. Y up. Characters ~1.8 m tall. Ground at y=0.
- Physics layers: 1 world, 2 player, 3 npc, 4 interactable, 5 food.
- All cross-system communication goes through `Events` signals.
- Scenes never reach into other scenes by path; they get references injected by `main.gd` or use groups: `player`, `hostile`, `restaurant`.
- Data is JSON; ids are snake_case strings. Challenge ids double as owner ids.
- No external asset downloads. Every model/texture is generated by a script in `tools/gen_assets/`, so assets are reproducible.

## Running
- Play: open project in Godot 4.3 editor, or `godot --path .`
- Tests: `godot --headless --path . -s tests/run.gd`
- Screenshots (software GL): `xvfb-run -a godot --path . --rendering-driver opengl3 -- --qa`
